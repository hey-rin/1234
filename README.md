## 사용과 내용 저장

index.html을 열거나 GitHub Pages 주소로 접속하세요.
이미지, 음악, 글씨체는 assets 폴더에서 불러옵니다. 폴더 이름과 파일 이름을 그대로 유지하세요.
브라우저가 음악 자동재생을 차단하면 음악 재생 버튼을 눌러주세요.

내용 편집으로 저장한 내용은 해당 기기의 브라우저에 저장됩니다. GitHub 파일이나 다른 기기로 자동 동기화되지 않습니다.
10월 월간 식단과 업무 자료는 홈페이지 코드에 포함되어 있습니다. 다음 달 자료는 추가 반영해야 합니다.
assets의 원본 엑셀을 수정하는 것만으로 홈페이지 식단 데이터가 갱신되지는 않습니다.
